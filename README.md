# Прогнозирование оттока клиентов для сервиса доставки кофе

## Задача
Сервис доставки кофе теряет клиентов. Цель проекта — построить модель машинного обучения, которая предскажет, уйдёт клиент в следующем месяце или останется. 
Это позволит бизнесу вовремя предлагать удержание и экономить бюджет на привлечении новых клиентов.

## Данные
Датасет `coffee_churn_dataset` (10 450 клиентов, 26 признаков). 
Целевая переменная `churn` имеет сильный дисбаланс: 94% (лояльные) к 6% (уходящие). 
Данные предоставлены платформой Яндекс.Практикум. Ноутбук содержит весь код для обработки и обучения модели.

## Что было сделано
1. **EDA (Исследовательский анализ):** 
   - Обработка пропусков (медиана/мода) и логических аномалий (отрицательные значения).
   - Анализ корреляций (коэффициент Phi_K), удаление дублирующих признаков.
2. **Feature Engineering:** Создано 11 новых признаков (квадратные корни, квадраты, отношения). Главный предиктор — `app_crashes_last_month_sq` (влияние сбоев приложения на отток).
3. **Моделирование:** 
   - Построен единый `Pipeline` (обработка данных → создание признаков → масштабирование → модель).
   - Подбор гиперпараметров через `GridSearchCV` (5-fold CV). Выбрана `LogisticRegression` с L1-регуляризацией.
4. **Валидация:** Порог классификации выбран на OOF-предсказаниях train по максимуму F1.

## Результаты на тестовой выборке
- **PR AUC: 0.744** (baseline 0.060)
- **ROC-AUC: 0.941**
- **Precision: 0.789**
- **Recall: 0.564**

## Ключевые выводы для бизнеса
1. Технические проблемы приложения (сбои, зависания) — главная причина оттока.
2. Клиенты с подпиской `pro` уходят чаще.
3. Модель сохранена в `coffee_churn_model.joblib` и готова к интеграции.

## Как запустить
1. Установите зависимости: `pip install -r requirements.txt`
2. **Данные:** Датасет `coffee_churn_dataset.csv` предоставляется платформой Яндекс.Практикум. Положите файл с данными в ту же папку, где находится ноутбук, перед запуском. 
3. Откройте ноутбук `coffee_churn_model.ipynb` и запустите все ячейки по порядку.
